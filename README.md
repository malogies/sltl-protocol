# SLTL — Secure Link Trust Layer™

SLTL is an open protocol specification for secure, verifiable digital actions.

Traditional links are unauthenticated, forgeable, and unsafe for sensitive operations.
SLTL defines a standard way to issue, verify, and enforce trust around links **before an action is executed**.

## Protocol vs Trust Authority

SLTL defines the protocol.

**SLTL Trust** (an Alpha91 brand at `sltltrust.com`; public verify endpoint at `sltl.global`) is the sole Trust Authority for the SLTL protocol.

Only verified issuers operating under SLTL Trust may represent links as **SLTL Trusted**.

Trust marks are owned by SLTL Trust, an Alpha91 brand; see `NOTICE.md`.
